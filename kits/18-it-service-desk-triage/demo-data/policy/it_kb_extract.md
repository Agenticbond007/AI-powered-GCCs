# IT knowledge-base extract (SYNTHETIC DEMO DATA)

> SYNTHETIC DEMO DATA — fictional. Not a real company, person, invoice, bank account, tax identifier, employee, or payment. For playbook testing only.

- VPN (Bengaluru / Hyderabad): install "Meridian Secure Access" from the company software centre. Sign in with work email and the authenticator app. Do not use a personal VPN. Home-network port 443 must be open. If the app reports "certificate untrusted", stop and raise a ticket — do not bypass the warning.
- Password resets: the service desk never resets a password from an email request alone. The user must pass the identity check (employee ID + last three digits of the staff badge, confirmed on a call or at the desk). Personal email addresses are not used for resets.
- Phishing: report to itservicedesk@meridian-gcc.example with the message unopened if possible. Do not click links or open attachments.
- Access to ERP, file shares or applications goes through the access-request process, with manager approval. The service desk does not grant access from a ticket comment.
